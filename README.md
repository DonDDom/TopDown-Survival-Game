# TopDown Survival Game (Python)
![ezgif com-crop](https://github.com/user-attachments/assets/146cf0df-d2af-49ac-8ff9-752e23068baf)

A room-based top-down survival game built with **Python** and **Pygame** as a portfolio project.
This project focuses on game logic architecture, room system , enemy wave management, boss mechanics, UI states and clean code structure rather than graphics.

---

## Gameplay Features

- Room-based combat system
- Enemy wave spawning
- Elite enemies with scaled stats
- Boss room with unique fight
- Dash & Stamina system
- HP bar & damage system with cooldown
- Chest & healing system
- Start menu , death screen , win screen
- Map loaded from CSV tile system
- Camera system
- Modular enemy logic

---

## What this project demonstrates

This project was built to demonstrate

- Structureing a larger Python project
- Managing game states (menu, game, win, death)
- Working with tile maps (CSV based)
- Collision and movement systems
- Enemy AI & wave logic
- Object-oriented design
- Seperation of concerns across files
- Handling real game loop architecture
